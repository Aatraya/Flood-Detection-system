## BENGALURU URBAN FLOOD RISK PREDICTOR 

## DESCRIPTION 
* This project is a machine learning pipeline used to predict risk of flooding in urban bengaluru areas
* The ML model uses a spatial cross validation with random forest algorithm to generate a reliable classification report.
* Using this model , the predict.ipynb creates a risk map and generates the areas with high flood risk.

## DATASETS USED 
* CHIRPS PRECIPITATION DATASET (https://www.chc.ucsb.edu/data/chirps)
* CARTOSAT - 1 DEM FROM BHOONIDHI WEBSITE (30 m X 30 m)
* BBMP FLOOD POINTS (https://data.opencity.in/dataset/flooding-locations-in-bengaluru-urban) [ GIVEN IN THE REPO]

  ## FEATURES USED FOR ML MODEL

  * TOTAL RAINFALL - RAINWATER ACCUMULATES OVER TIME TO CLOG DRAINS CREATING STAGNATE WATER
  * MEAN RAINFALL - HIGHER RAINFALL IN AVERAGE WILL LEAD TO A HIGHER CHANCE OF FLOODING
  * SLOPE - STEEP SLOPES DRAIN QUICKLY WHILE LOW SLOPES BECOME WATER COLLECTION SPOTS
  * HEIGHT FROM SEA LEVEL - LOWER ELEVATION AREAS BECOME NATURAL WATER COLLECTION POINTS
  * MAX RAINFALL - PEAK RAINFALL IN ONE DAY CAN TRIGGER FLASH FLOODING
 
  ## WORKING OF TRAIN.IPYNB

  * TERRAIN PROCESSING - TWO DEM TILES FROM ISRO CARTOSAT - 1 ARE STITCHED TOGEHTER USING THE rasterio MODULE . LOCAL SLOPES ARE COMPUTED USING SOBEL
 
  * RAINFALL FEATURES - THE CHIRPS FILE IS REPROJECTED ON THE DEM TILES AND THE RAINFALL FEATURES ARE SEPERATED
 
  * LABEL PREPARATION - 129 BBMP FLOOD POINTS ARE MAPPED TO PIXEL INDICES. SAMPLING IS DONE IN 3:1 RATIO
 
  * MODEL - RANDOM FOREST CLASSIFIER IS TRAINED WITH SPATIAL CROSS VERIFICATION OVER 4 ZONES. THE MODEL IS SAVED AS A .pkl FILE

## WORKING OF PREDICT.IPYNB

* LIVE FORECAST FETCH - 3 DAY LIVE FORESTCAST IS FETCHED AND FEED TO THE MODEL TO GENERATE A RISK MAP
  
* REVERSE GEOCODING - PIXELS ARE REVERSE GEOCODED TO FIND THE AREA WHICH IS AT RISK OF RAINFALL . THE THRESHOLD FOR PROBABLITIY IS SET AT 0.20 

* SCENARIOS EMULATED ARE CURRENT FORECAST, 2022 RAINFALL EVENT(150 MM) AND EXTREME MONSOON(300 MM).

* HIGH RISK AREAS IN EXTREME MONSOON SCENARIO WERE : Abdul Kalam Nagar · BEL Colony · Chamarajapete · Dodda Nekkundi · Electronic City · Electronics City Phase 1 · Gandhi Bazaar · Goripalya · Jayanagar East · Kalyani Nagara · Kodihalli · Kogilu · Koramangala West · Kothnur · Mavalli · Nagarbhavi · Sampangirama Nagar · Srirampura · Talagattapura + 55 more


## MODEL 

* ALGORITHM - RANDOM FOREST CLASSIFIER
* PARAMETERS -  200 trees, max depth 10, min samples per leaf 5, balanced class weights
* TRAINING SAMPLES -  508 (127 flood + 381 non-flood)
* VALIDATION - Leave-One-Group-Out Spatial Cross-Validation across 4 geographic zones

## WHY SPATIAL CV 

* ON RANDOMLY PICKING PIXELS WORKS WHEN THESE PIXELS ARE INDEPENDENT OF EACH OTHER. HOWEVER, IN THIS CASE TWO PIXELS IN THE SAME AREA NEED NOT BE INDEPENDENT . HENCE, SPATIAL CV IS NEEDED. THIS ENSURES THAT THE MODEL LEARNS FLOOD PHYSICS


## LIMITATIONS 

* TEMPORAL CV CANNOT BE DONE AS THERE ARE NO TIMESTAMPS ASSOCIATED WITH THE FLOOD_POINTS.KML FILE . THIS IS A KNOWN OPEN DATA GAP IN FLOOD RESEARCH (OPEN CITY , 2022) [ https://opencity.in/bangalore-floods-a-call-for-open-data/]

* UNIFORM RAINFALL INFERENCE - THE PREDICTION.IPYNB APPLIES SINGLE SCALAR TO THE ENTIRE GRID . RAINFALL IS SPATIALLY DISTRIBUTED

* PROBABILITY CEILING - CITY AREA PIXELS TOP OUT AT PROBABILITY 0.27 EVEN IN EXTREME SCENARIOS , REFLECTING CONSERVATIVE GENERALISATION

* THE MODEL DOESNOT ACCOUNT FOR BLOCKED INFRASTRUCTURE LIKE STORM DRAINS ETC
